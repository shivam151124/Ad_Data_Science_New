# Ad_Data_Science_New

## 📌 Overview

This repository contains Data Science projects focused on data analysis, data cleaning, visualization, and practical data-driven problem solving using Python.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## 📂 Project Included

### Data Importing and Basic Data Cleaning

This project demonstrates the process of importing a dataset into Jupyter Notebook and performing basic data cleaning using Pandas.

**Dataset Used:** `trends.csv`

### Cleaning Tasks Performed

* Imported the `trends.csv` dataset
* Checked and handled missing values
* Removed duplicate records
* Corrected inconsistent text entries
* Converted data types appropriately
* Standardized column names
* Checked data formatting
* Verified the final cleaned dataset
* Saved the cleaned dataset as `trends_cleaned.csv`

## 📊 Dataset Information

The dataset contains the following columns:

* `location`
* `year`
* `category`
* `rank`
* `query`

### Final Dataset

* **Rows:** 26,945
* **Columns:** 5
* **Missing Values:** 0
* **Duplicate Records:** 0

## 🎯 Objectives

* Import and understand the dataset
* Clean and prepare data for analysis
* Handle missing and duplicate records
* Standardize data formatting
* Ensure correct data types
* Prepare a clean dataset for further analysis

## 🚀 How to Run

1. Clone this repository
2. Install the required libraries
3. Open the Jupyter Notebook
4. Make sure `trends.csv` is available
5. Run the notebook cells step by step
6. The cleaned dataset will be generated as `trends_cleaned.csv`
